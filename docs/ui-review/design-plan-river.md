## 2. 为什么现在不好看（先诊断，再开方）

用户看的是 `docs/ui-review/after-theme4-1440/river-1440.png` 那一版。**逐条对照 `frontend-design` 的「AI 生成感」清单**：

| `frontend-design` 原文                                                                                                                                           | 当前实现                                                                                                 | 判定                                        |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- | ------------------------------------------- |
| "the SaaS-card kit: content chopped into identical rounded cards, one border-radius on everything regardless of hierarchy, the same soft grey shadow under each" | 两个**同宽、同高（517px）、同圆角、同底色、同阴影**的深色 `<section>`，各自居中一个同心圆 + 一段居中说明 | ❌ **正命中**                               |
| "a tracked-out ALL-CAPS eyebrow label above every heading"                                                                                                       | 没有                                                                                                     | ✅ 未命中                                   |
| "meta strings joined with middle dots ('A · B · C')"                                                                                                             | 页脚两条并列文字链接即此形态的弱化版                                                                     | ⚠️ 需收敛                                   |
| "a '→' appended to link and button text"                                                                                                                         | 没有                                                                                                     | ✅                                          |
| "fade-and-slide-up entrances on each section and hover transitions on every card"                                                                                | 有（`enter-rise` + `hover-lift`）                                                                        | ⚠️ 保留但**不新增**，本页不加第二个主角动效 |

**另外三条与主题直接相关的问题**：

1. **「河道」这一页看不到河道**。`CONTEXT.md` §2/§4.1 说河道是「单支路、同一瓶子同一时间只有一个持有者」——
   这是整个产品最独特的一条规则，而页面上没有任何东西在表达「流动 / 单向 / 一条水道」。
2. **同心圆读起来像雷达/靶心，不像水**。三个**正圆**等距、等粗、同色，是几何图形，不是水面。
3. **音乐只剩一个 `Music` 图标**。四个主题词里，音乐在首屏的存在感是 24px 的一个图标。

## 3. 胆量只花在一处（`frontend-design`「Spend your boldness in one place」）

**花在「水线 + 水体」这一处。** 其余一切（标签、链接、说明文案）保持安静：不加边框、不加阴影、不加第二套装饰。

具体：**河道剖面（river cross-section）**——不是俯视图、不是卡片、不是 hero 图，
而是一刀切开的河：上面是岸（浅底），下面是深水（渐变），中间一条水线。

```

      │───────────────────────── 水 线 ──────────────────────────────│  ← 唯一的横线（sea-glass 渐隐）
      │░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░│

      │░  ╰──╯                            ╰──╯                    ░│      → trench 渐变
      │░        捞一个漂流瓶          投下一支漂流瓶                 ░│
      │░        捞取深海深处传来的…    选一首歌，录下第 1 段…         ░│
      │░                                                            ░│
      │░   ～～～～～～～～～～～～～～～～～～  ← 河道主流（= 声波包络）  ░│  音乐母题：主流线画成波形
```

**这个构图一次装下四个主题**：海洋（深水剖面 + 水下光柱）、河道（水线 + 主流 + 上下游）、
漂流瓶（沿主流漂过的瓶）、音乐（主流线画成声波包络 —— 「声波即水波」）。

**为什么捞在左、投在右**：`捞` 是新用户的第一动作，按阅读顺序放先；水流因此**从右往左**（上游在右）。
这个方向由 `wake-line` 的朝向 + 瓶子漂移方向共同暗示，**不写文字解释**。

## 5. 逐层规格

### 5.1 色彩（**不新增任何颜色**）

| 层                 | 取色                                                                           | 依据                                  |
| ------------------ | ------------------------------------------------------------------------------ | ------------------------------------- |
| 岸（水线以上）     | `wave-white` + `.water-sheen-light` + `.water-texture-light`                   | 现有浅底基线                          |
| 水体（水线以下）   | **新 token `gradient.river`**：`peacock-deep` → `deep-current`(44%) → `trench` | 三个既有深水色，**不发明新色**        |
| 上行泊位（投下）   | `coral` / `coral-deep`                                                         | 既有：coral 只在 CTA 强调与危险态出现 |
| 下行泊位（捞取）   | `peacock` / `sea-glass` 涟漪                                                   | 既有：主品牌色                        |
| 水线 / 光柱 / 主流 | `sea-glass`、`lagoon` + 新强度 token                                           | 既有：这两个色本来就只作装饰与高光    |

### 5.2 字体

- 页标题用 **`DESIGN.md` typography.hero**（`clamp(2.5rem, 5vw, 4rem)`，Quattrocento 700 + 霞鹜文楷 700）。
  **现状是 1.5rem（h2 档）—— 门面页用了次级标题的字号，这是排版上最大的一处浪费。**
- 副标题 `1rem / slate-current`；泊位小标题 `1.125rem / 600`；说明 `0.875rem / 1.6 / on-dark-muted`。
- 数字（段数、秒数、72 小时）一律 Quattrocento（`--font-latin`）。

### 5.3 动效（`motion-web` §10 十问答）

| #   | 动效             | 目的                                                                           | token                                          | 退场/降级                                                        |
| --- | ---------------- | ------------------------------------------------------------------------------ | ---------------------------------------------- | ---------------------------------------------------------------- |
| 1   | 漂流瓶沿主流通过 | **decoration**（产品理由：河道里必须有东西在漂；`§95` 用户裁决「水缓缓流动」） | 新增 `motion.passageDuration` / `passageShift` | CSS 动画 ⇒ 被 `motion.css` 全局 `animation:none !important` 冻结 |
| 2   | 水面肌理横向漂移 | decoration（t46 已有）                                                         | `motion.driftDuration` / `driftShift`          | 同上                                                             |
| 3   | 泊位涟漪         | decoration（hero 常驻母题，`DESIGN.md` 角色②）                                 | `motion.rippleDuration`                        | 同上                                                             |
| 4   | 页面入场         | continuity（t 已有 `enter-rise`）                                              | `motion.entryShift` / `entryDuration`          | reduced-motion 下 → 150ms opacity                                |

**只动 `transform` / `opacity`**；没有 JS/WAAPI 动画；没有新增第二个「主角动效」（`motion-web` §4：
一个交互只允许一个主角）。**动效不是唯一反馈**：捞取的 pending 态有 `aria-live` 文字（既有）。

### 5.4 一屏与滚动（用户本轮豁免）

本构图按「一幅画占满首屏」设计，**不为了 900px 砍构图**。代价与回滚见 §7。
