## 1. `p-songpicker-record.html`（选一首歌）—— 现在 = "列表 + 一颗大圆"
**问题**：右侧 r150 盘 + 两外环是**全页最大的圆**，纯装饰风险只靠 1px 珊瑚沟压住。
**方向（候选，先自评再选）**：
- **A 唱片店的翻页箱**：整页是一列**站着的唱片**，每行只露出**卡沿（上沿）**与一条细边，像在箱子里翻。
  作者已在检索牌那一角做了"5 张卡沿"，把它扩成整页结构；**把右侧大圆收掉**（未刻母版的四道段位沟移进每行的卡沿里当刻度）。
- **A+ 水箱里的水位**（哪首"切好了"= 浸在水里、哪首"还没有切分"= 干着）：把 `这首还没有切分，暂不能发起` 这条状态画成**水位差**，而不是只写一行字。
- B 保留大圆只弱化：治标不治本，否决。

## 2. `s2-admin-record.html`（审核台）—— 现在 = "深色表格"
**问题**：压片工单 + 裁决印章的想法成立，但**排得太整齐**，像后台表格；且没有任何水/瓶装置。
**方向**：
- **A 真印章**：裁决印章带 **±2~4° 随机旋转**、边缘墨色不匀，并且**压在行与行的分界线上**（真盖章不会落在格子里）。一处改动就能把"表格"变成"有人盖过章的工单"。
- **A+ 浮上来的东西**（§7 的水装置）：待处理队列＝**刚从深水里浮上来**的对象 —— 每行带一圈涟漪 + 两三颗上升气泡；「待处理」= 还没沉下去、「已裁决」= 已归档。数量本身即信息。
- B 红笔批注体：需要新字体，否决。

## 3. `p-settings-record.html`（设置）—— 现在 = "一份印刷品"
**问题**：纯文字排版 + 几乎看不见的压印弧；在缩略图尺度看不出唱片身份，也没有水。
**方向**：
- **A 内袋里的说明书折页**：整页是一张**对折的说明书**（真实折痕 = 1px 亮线 + 两侧明暗差、斜切角、一处 die-cut 指孔），左右两栏＝折页的两面。与登录页的"封套"同族但**不同物件**。
- **A+ 把「匿名的边界」画成一条水线**（§7 的水装置，且**这是真信息映射**）：
  **水线之上 = 别人看得到的**（每支瓶子的独立代号、你的声音）；
  **水线之下 = 只有你自己知道的**（账号、邮箱、"账号只用于认领"）。
  三条边界本来就是"哪一面朝外"，水线正好是它的图形表达 —— 不是装饰。
- B 盘面 runout 刻字：环形文字可读性差，否决。
