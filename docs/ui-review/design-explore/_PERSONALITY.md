# 「加个性」pass —— 四张偏弱页的重塑方向

> 背景：`_contact-sheet.png` 的并排对照暴露了**太均匀**风险 —— 9 张里多数是「左上大标题 + 细纹理 +
> 小型元信息 + 细线 + 列表」，缩到 480px 宽彼此像同一页的变体。用户裁决：**保留公共层，给偏弱的
> 四页各一个真正属于它自己的构图想法**。
>
> 铁律不变：公共层（§`_LANGUAGE.md` 的字体/七色/圆的语法/边缘微光/元信息字距）**一字不改**；
> 变的是**这一页的构图想法**。每页开工前仍要先brainstorm 3 个方向。

---

## 1. `p-settings-record.html`（设置）—— 现在像"一份印刷品"

**问题**：纯文字排版 + 一个几乎看不见的压印弧，缩略图尺度下看不出唱片身份。

| 候选方向 | 判断 |
| --- | --- |
| **A 内袋里的说明书折页**（insert）：整页是一张**对折的说明书**插在唱片内袋里 —— 有真实折痕（1px 亮线 + 两侧明暗差）、有斜切的角、有一处 die-cut 指孔 | **选它**：折页是唱片实体的一部分，与登录页的"封套"是同族但**不同的物件**；折痕天然提供分栏依据（左右两栏＝折页的两面） |
| B 盘面 runout 刻字（最内圈的死槽刻着母版号与版记） | 上一批作者已评估过：环形文字可读性差，**否决** |
| C 印刷厂规格栏（bar code + 裁切标记做成主视觉） | 容易变成"包装设计海报"，与产品气质偏 |

## 2. `s1-sea-record.html`（公海大厅）—— 现在读成"深色列表"

**问题**：一行=一张封套背，想法对，但整页仍是"标题 + 列表"，没有物件的边。

| 候选方向 | 判断 |
| --- | --- |
| **A 封套的背面 + 书脊**：整页就是**一张摊开的封套背面**，左边 24px 是**书脊**（竖排曲名 + 编号），列表是背面的**曲目表**（tracklist），带曲目序号与时长（Quattrocento） | **选它**：bookspine 给了这页一个**物理边缘**，"曲目表"是唱片文化里真实存在的东西，且天然容纳"曲名/时长/状态"这些字段 |
| B 唱片架正面（封套正面网格） | 会丢掉 `进度/状态/最近更新` 这类字段，且与选歌页的"翻页箱"撞 |
| C 压片出货清单 | 撞审核台的工单语言 |

## 3. `s2-admin-record.html`（审核台）—— 现在读成"深色表格"

**问题**：压片工单 + 印章的想法成立，但**排得太整齐**，像个后台表格。

| 候选方向 | 判断 |
| --- | --- |
| **A 真印章**：裁决印章**带 ±2~4° 的随机旋转**、边缘有轻微的墨色不匀（用渐变+1px 内描边做旧），并且印章**压在行与行的分界线上**（真盖章不会落在格子里） | **选它**：一处改动就能把"表格"变成"有人盖过章的工单"；且不破坏信息结构 |
| B 红笔批注体 | 需要新字体，违反"不引入字体" |
| C 待处理队列做成"待质检的唱片堆" | 与"我的=唱片柜"撞装置 |

## 4. `p-songpicker-record.html`（选一首歌）—— 现在读成"列表 + 一颗圆"

**问题**：右侧 r150 盘 + 两外环是全页最大的圆，**大圆装饰**风险只靠 1px 珊瑚沟压住。

| 候选方向 | 判断 |
| --- | --- |
| **A 唱片店的翻页箱**（flip-bin）：整页是一列**站着的唱片**，每行只露出**卡沿（上沿）**与一条细边，像在箱子里翻 —— 作者已经在检索牌那一角做了"5 张卡沿"，把它扩成整页的结构 | **选它**：它把"列表"变成"一个可以翻的箱子"，是这一页独有的物件；顺带**把右侧大圆收掉**（未刻母版的四道段位沟可以移进每行的卡沿里当刻度） |
| B 保留大圆、只弱化 | 治标不治本 |
| C 搜索框做成唱片店检索抽屉 | 已经是了，不够撑起整页 |

## 交付要求（与前一批一致）

- 一页一个文件（就地改，不新建）；**不删任何文件**；不改别人的稿；不改 `_shoot.mjs`；不跑 git。
- 渲染：`node docs/ui-review/design-explore/_shoot.mjs`（png 比 html 新会 skip，你改完自然重画）→ 必须 `1440x900 ✓ 一屏内`。
- **必须 `read_image` 亲眼看图，至少 3 轮**。
- 机械自检：无 emoji（含 ♪）/ 无纯黑（掩膜用白）/ 无外链 / `@import` 四行保序 / 圆角 ≤4px（`50%` 与半圆合法）。
- 汇报：① 3 个方向与选择理由；② 最终参数（数值）；③ 自评改了什么；④ **最大的弱点**；⑤ skill 条款要点。
