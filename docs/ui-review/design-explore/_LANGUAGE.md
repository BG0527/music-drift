# 唱片主题 · 全站设计语言（record-v1）

> 本文件是**并行开工的语言契约**。所有页面共用 §1 公共层；每页再按 §3 领自己的**母题装置**。
> 铁律：**母题必须承担信息，不能只做背景。** 10 个页面都画一颗大圆 = 失败。

---

## 0. 一句话

产品是「匿名接力的音乐共创社区」。视觉母题是**一张黑胶唱片**：
**一条沟槽 = 一条河道**，**一枚标签盘 = 一支作品**，**唱针 = 播放头**，**印章 = 裁决**。

用户口径（原话）：**颜值大于一切**；要高级感、设计感、艺术感；**不要平庸**，不要"只是做了个页面"，
而是**用这个主题做设计**；目标是**拿奖级别的落地**。

## 1. 公共层（所有页面必须一字不差地一致 —— 这是"切换页面不跳脱"的唯一保障）

### 1.1 画布
```css
html,body { width:1440px; height:900px; }
html { overflow:hidden; }
```
- 出血装饰**必须**包在 `<div class="clip">`（`position:absolute; inset:0; overflow:hidden`）里 —— 否则撑大 `scrollWidth` = 横向溢出。
- 一屏门禁是**机器可判**的：`_shoot.mjs` 会打印 `1440x900 ✓ 一屏内`；出现 `⚠ 超出一屏` 必须修到 ✓。

### 1.2 字体（四行 `@import` 原样复制，顺序不许改）
```css
@import url('/node_modules/.pnpm/lxgw-wenkai-webfont@1.7.0/node_modules/lxgw-wenkai-webfont/lxgwwenkai-regular.css');
@import url('/node_modules/.pnpm/lxgw-wenkai-webfont@1.7.0/node_modules/lxgw-wenkai-webfont/lxgwwenkai-bold.css');
@import url('/node_modules/.pnpm/@fontsource+quattrocento@5.3.0/node_modules/@fontsource/quattrocento/400.css');
@import url('/node_modules/.pnpm/@fontsource+quattrocento@5.3.0/node_modules/@fontsource/quattrocento/700.css');
```
- 正文/标题：`font-family:'LXGW WenKai',serif`。
- **数字与元信息：`Quattrocento`**（`.mono { font-family:Quattrocento,serif; font-variant-numeric:tabular-nums; }`）。

### 1.3 色（**只准用这些**；明度/透明度可派生，**不许引入新色相**）
```css
:root {
  --ink:#050f14;      /* 盘面底。**禁纯黑 #000** */
  --paper:#f3f9fa;    /* 正文/标题 */
  --muted:#a9c7cf;    /* 次要文字 */
  --glass:#7fd1d9;    /* 冷光：链接、已达成、冷边 */
  --coral:#c7452c;    /* **唯一强调色**：标签盘、印章、当前项 */
  --warm:#f6d79a;     /* 暖光：等待态、"投下"一侧 */
  --line:rgba(243,249,250,.13);  /* 分隔线 */
}
```
正文对比度 ≥ 4.5:1（`--muted` 已是下限，不要再用更暗的文字色）。

### 1.4 唱片表面（背景层，**质感必须看起来是同一张唱片**，密度可按页微调）
```css
.platter { position:absolute; inset:0;
  background:
    repeating-radial-gradient(circle at 1420px 960px, rgba(216,243,246,.055) 0 1.2px, transparent 1.2px 6.5px),
    radial-gradient(circle at 1420px 960px, rgba(127,209,217,.05) 0 30%, transparent 68%); }
.glint { position:absolute; inset:0; mix-blend-mode:screen;
  background:linear-gradient(101deg, transparent 28%, rgba(228,247,252,.045) 45%, rgba(228,247,252,.065) 50%, rgba(228,247,252,.028) 55%, transparent 72%); }
```

### 1.5 「圆」的语法
- 圆盘 `border-radius:50%`；外环最多 3 圈：`inset:-13px / -29px / -45px`，边框 `rgba(228,249,252,.42/.2/.1)`。
- 圆盘填充：`radial-gradient(76% 76% at 34% 26%, rgba(10,48,60,.5), rgba(3,17,23,.78))`。
- **盘身不填彩色**；彩色只出现在**边缘微光**上：冷 `rgba(203,238,246,.7)`、暖 `rgba(246,215,154,.66)`。

### 1.6 排版语法
- 元信息：`11px` + `letter-spacing:.24em` + `Quattrocento`，色 `rgba(243,249,250,.5)`（如 `SIDE B · 已入海`、`QC · 母版检验`）。
- 标题：`56–62px`，`font-weight:700`，`line-height:1`。
- 副标题：`14.5–15.5px`，`line-height:1.85`，色 `--muted`，**宽度 ≤ 820px**。
- 圆角 ≤ 4px（按钮 2px）；**不用阴影造层次**，用亮度差与 1px 细线。
- **圆角的例外（并行批次暴露的歧义，现写明白）**：`border-radius:50%` 与**半圆**（`半径 = 高度/2`，例如唱片封套右上角那个开口缺口）属于 §1.5「圆的语法」，**允许**；禁止的是"大圆角胶囊/药丸"那种无理由的圆。
- **掩膜一律用白**：`mask-image` 只读 alpha，写 `rgba(0,0,0,α)` 与白色等价，但会撞"禁纯黑"检索 —— 统一写 `#fff` / `rgba(255,255,255,α)`。
- **禁止**：用「·」把一长串元信息串起来（唱片标签处最多一个）、AI 陈词、lorem ipsum。

### 1.7 动效
本轮是**静态设计稿**：**零动效**。如确有需要，只动 `transform`/`opacity`。

## 2. 母题装置库（每页**至多 2 个**；相邻页不得重复同一装置）

| 装置 | 它编码什么信息 | 建议归属 |
| --- | --- | --- |
| 封套 + 标签盘 | 一支作品的身份 | 公海大厅（一行 = 一张封套背） |
| **4 格段位刻度** | 进度（已录 N / 4 段） | 公海大厅、选歌、瓶子详情 |
| **唱针 + 沟槽 = 播放头与时间轴** | 播放位置 / 段链顺序 | 公海作品详情 |
| 母版号 `MDB-0001-A` | 作品与段的唯一标识 | 详情、审核台、日志 |
| **压片工单 + 裁决印章** | 审核结论（待处理/已删段/已恢复） | 审核台 |
| 刻痕短弧 | 时间线上的一笔 | 漂流日志 |
| 唱片柜 / 内袋 | 我的收藏与参与 | 我的 |
| 封套背面小字（liner notes） | 说明性长文本 | 设置、登录的小字 |
| 划伤 / 跳针 | 出错、找不到 | 404 |
| 空白母版 / 刻录 | 发起、把这一段"刻进去" | 选歌、瓶子详情 |

## 3. 每页必须装的信息（**字段来自源码，不许增删、不许臆造**）

- **公海大厅**：曲名 / 已录 N 段 / 缺第 x 段 / 状态（全部段位都有人唱过 · 成品里这段时间是静音）/ 最近更新 / 「听这支作品」；Tab：完整作品 · 等待接力；真分页（共 N 页）；空态两句 + 「去河道捞一个」。
- **公海作品详情**：面包屑 / 状态 / 入海时间 / 沉浸式播放区（`<audio>`）/ 段链（4 段，未唱的显示「这一段还没有人唱」）/ 参与者（匿名代号）/ 「混音导出计划：四段按序拼成纯人声版本，缺口留成静音」/ 「这支作品还有缺口。缺口是歌里固定的段位，成品里留成静音，不会被别人的段顶替。」
- **选一首歌**：标题「选一首歌，投出第一棒」/ 说明「这里每首歌都被切成固定段位（同一位置永远属于同一段，斩浪也不会把后面的段前移）。你录第 N 段，之后交给河道里的陌生人。」/ 按曲名过滤（输入框）/ 曲目列表（曲名 / 来源 / 每段约 N 秒 / 这首还没有切分，暂不能发起）/ 「选这首，录第 N 段」/ 空态。
- **瓶子详情（录制+接力）**：面包屑「回河道」/ 标题「漂流瓶详情」/ 发起者徽记 / 段链（4 段，缺口标注「缺口是歌里固定的段位，不会被别人的段顶替。成品里这段时间会留成静音。」）/ 试听与投票（赞/踩）/ 录制入口（第 N 段由你开第一句）/ 三选一去向：**继续投河 · 回传 · 入海**（发起者没有"回传"）/ 举报 / 私密留言 / 匿名代号。
- **漂流日志**：面包屑「回漂流瓶」/ 标题「漂流日志」/ 说明「这里只记核心操作：发起、接唱、捞取、投河、回传、入海。操作者只显示匿名代号。」/ 时间线（`<ol>`，升序，服务端为准）/ 每条：操作类型 + 匿名代号 + 时间。
- **我的**：身份卡（账号只用于认领自己的漂流瓶；别人只看到匿名代号）/ 管理员·普通用户标记 / 我参与过的漂流瓶（跨设备、被斩的段也算）/ 我的收藏 / 我的徽章 / 消息（只显示你自己的；留言送达·未送达·作品进公海）。
- **设置**：匿名的边界三条（每支瓶子一个独立代号；别人拿不到你的账号；账号只用于认领）/ 当前身份（未登录 / 已登录）/ 登出（只清掉这台设备的会话）/ 伴奏与授权（CC BY 4.0 署名义务 → 「查看署名与许可」）/ 契约版本 / 环境提示（录音只在 `https://` 或 `localhost` 下可用）。
- **审核台**：Tab 待处理 / 历史裁决 / 每行：举报对象（瓶子·唱段·留言）+ 举报时间 + 状态徽记（待处理·已处理·已驳回·已删段·已恢复唱段·已删瓶下架·已封禁作者）+ 动作（**按对象类型**：唱段→驳回·删段·封禁作者；瓶子→驳回·删瓶下架·封禁作者；留言→驳回·封禁作者）/ 历史里的「恢复这一段」/ 非管理员态：「审核台只对管理员开放」。
- **登录**：标题「每一段旋律，都在寻找下一个声音」/ 说明「这是一个由歌声、回音和宿命组成的角落。你只录一段，剩下的交给漂流。」/ 用户名 + 密码 / 密码规则（≥8 位且同时含字母和数字）/ 「注册并进入」/ 「不用真名，不用露脸，只要一段声音。同一个瓶子里，不同的人看到的是不同的匿名代号。」/ 已登录态：「你已经登录为 X，不用再登录一次」+ 「直接去河道捞一个瓶子」。
- **404**：标题「找不到这一页」/ 「这条水路不存在」/ 说明「这个地址可能是旧的，或者瓶子已经被别人接走、链接失效了。」/ 「回首页」/ 「也可以换个入口继续：去河道捞一个漂流瓶 · 去公海听完成的作品」。

## 4. 交付要求（每个页面）

1. 一个页面一个文件：`docs/ui-review/design-explore/<页名>-record.html`（例：`p-bottle-record.html`）。
2. 渲染：`node docs/ui-review/design-explore/_shoot.mjs` → 输出必须含 `1440x900 ✓ 一屏内`，**出现 `⚠ 超出一屏` 就修到 ✓**。
3. **必须 `read_image` 亲眼看自己的图**，改，再看 —— **至少迭代 3 轮**。
4. 机械自检（自己跑一遍再说"完成"）：无 emoji 字符（含 `♪` U+266A、箭头）、无纯黑、无 `http(s)://` 外链、`@import` 四行保序、字段与 §3 一致。
5. 开工前**先头脑风暴 3 个方向**（写下来），再选一个做；**不许第一版就交**。

## 5. 汇报格式（缺一项视为未完成）

```
① 头脑风暴过哪几个方向、为什么选这个；
② 最终参数（数值：尺寸/间距/色值/字号）；
③ 自评后改掉了什么（每轮都看图）；
④ **这一版最大的弱点**（不许写"没有弱点"）；
⑤ 引用到的 skill 条款（写要点）。
```

## 6. 硬约束

- 只写分配给你的文件；**不改别人的 html、不改 `_shoot.mjs`、不跑 git、不装依赖**。
- 文案只准用 §3 的字段与现有文案；**不得发明业务事实**（业务规则唯一来源是 `CONTEXT.md`）。
- 禁：emoji、纯黑、横向溢出、lorem ipsum、AI 陈词、圆角 > 4px、用阴影造层次。
- **不要平庸**：如果你的稿子和"一个深色后台模板"长得很像，那就是失败，回去重想。
