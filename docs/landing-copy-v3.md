## 0. 全局约定

- **双轴主心**：轴一 · 声音案底（身份侧，解决"敢不敢唱"）；轴二 · 计数与回应（关系侧，解决"唱了值不值"）。
- **文风**：全程文艺诗意；**只用听觉词，不用视觉词**（听/唱/声音/耳朵，不用 看/见/曝光/光）；
  事实只用既有规则（约 20 秒 / 4 段 / 80% / 72 小时 / 48 小时）；不编造数据与证言。
- **红线（继续有效）**：无 emoji / 无 AI 陈词 / 无 lorem / 无 15–30 旧口径 / 无内联 hex /
  无 h-screen / 无"所有人能用"类绝对化 / 不逐字出现用户示例
  （"想唱但怕被评价""不用露脸""不用唱完""不用等点赞"）。
- **标题系统（用户选定方案 A · 瓶语线）**：八屏标题一眼可读 + "漂/瓶"词汇隐形串联；
  机制术语（投河 / 河道 / 入海 / 公海）保留官方口径；标题不以"河"作主角。
- **结构**：8 屏（原 7 屏 + 新增"它漂到哪儿了"等待屏），翻页交互不变。

## 2. 屏 00 · 开场（首屏，方案乙 · 对仗）

- 眉题：音乐共创 · 匿名接力
- **h1 钩子：唱过无痕，声声有应。**
- 定义（v3 放宽至 32 字，用户定稿；测试 ≤32 同步）：
  匿名接力唱：唱约 20 秒投进河里，陌生人接唱下一段，四段拼成一首。
- 价值句：不署名，不入册，不比谁唱得好——只问一件事：有没有人，接住你的声音。
- CTA：唱一段投进去 → `/new`
- 体验卡：眉题「公海成品 · 免注册」；引句「四段接力拼成的一支成品，点开就能听。」；
  脚注「不用注册，也不用麦克风——现在，只负责听。」；播放器功能文案不动
  （当场听一支成品 / 暂停 / 继续听 / 从头再听一遍）。

## 3. 屏 01 · 漂流瓶，是什么

- 定位句：一个基于匿名接力的音乐共创社区——唱一段，投进河里，让陌生人接棒，最终汇入公海。
- 正文：这里不收整首歌，只收你敢开口的 20 秒。四段声音来自几位陌生人，合成一首没有主角的歌。
- 张力句（coral，保留原句）：我的声音会和谁的声音拼在一起？
- 四词表：
  - 漂流瓶 — 一段尚未唱完的歌，正在河上
  - 河道 — 没有搜索，没有关注——只能随机遇见
  - 公海 — 所有歌的终点，谁都能来听
  - 匿名代号 — 一只瓶一个名字，出瓶即隐身

## 4. 屏 02 · 怎么漂起来

三步（`<ol>` 序号步骤）：

1. **唱一段** — 挑一首你熟的歌，系统替你切成四段，每段约 20 秒；你只录第 1 段。
2. **投进河** — 不挑听众，不看主页，谁捞到它，由河说了算。
3. **接力拼完** — 捞到的人续唱下一段，可以继续投河，也可以沿着来路把整首歌送回你手里；四段齐了，入海。

- 回传句（§4.4 原句保留）：回传让作品不只是被陌生人接续，而是被陌生人接力送回家。
- 水位句：瓶中水位 = 已唱段数：四段齐了才入海。

## 5. 屏 03 · 歌，都漂去哪儿（三列五行对比表 v4）

| 对比维度 | 原漂流瓶 | 现有合唱 | 本品 |
| --- | --- | --- | --- |
| 录完之后 | 歌停在草稿箱，等一个敢 | 挂在账号上，等一个指定的人 | 投进河里，河替你遇见下一个人 |
| 开始的条件 | 自己独唱 | 指定的人，无法随机 | 随机捞起，听见心动就接唱 |
| 对方是谁 | 以账号相见，透明可查 | 双方账号透明，固定两人 | 一个只属于这只瓶的代号 |
| 同一首歌有几个人 | 只有你 | 固定两个人 | 多人接力，由陌生人拼成一首 |
| 作品给谁欣赏 | 留在你自己的主页 | 两个人的账号 | 入海——所有人的公共作品集 |

表下（顺序照锁定）：

1. 行 2 展开句：合唱要先指定对方，配不上就开不了口；这里没有配对——随机捞起一个陌生的声音，听见喜欢的，就接下去。
2. 草稿箱句（D-c）：有些天籁不缺勇气，只差一个没听过你的听众。
3. 结论句（F2 漂流版）：你负责开口，剩下的交给漂流。

竞品事实口径（用户提供，不得扩写）：原漂流瓶 = 独唱（可选片段）+ 账号级透明互动；
现有合唱 = 双方账号透明、固定两个人、指定人配对（无法随机）。

## 6. 屏 04 · 什么时候，漂一瓶（恰 3 场景，栅格 3/2/2 非对称）

- **通勤** — 挤在地铁里捞起一个瓶子，唱一段；到站之前，刚好唱完。
- **睡前** — 灯关了，世界只剩你和伴奏。录一段投出去，关上手机，让它自己漂。
- **午休** — 吃完饭接别人的一段，回工位的路上，这支歌又多了一段。
- 每卡脚注：一段约 20 秒
- 收束句（保留原句）：一段歌的长度，一次开口的勇气。

## 7. 屏 05 · 它漂到哪儿了（新增等待屏 · 轴二）

- 引句：等待不是空白——日志里每一行，都是有人来过。
- 四卡（md:grid-cols-2）：
  - **漂流日志** — 你的瓶子漂到哪了，随时看得见：每一棒的代号，每一次出手的时间。只给你自己看。
  - **漂流中** — 「已传 3 棒 · 最后活跃在 2 小时前 · 正在等待下一棒」。你只看得见自己唱过的部分——后面是什么，是悬念。
  - **揭晓** — 入海那一刻，完整接力链才解锁：谁接过你的歌，在哪儿接的，每一句附言。
  - **敲门** — 完成时它会来敲门：「你参与过的漂流瓶已完成，点击查看完整接力链。」
- 脚句：你等的不是点赞数，是下一棒的脚印。

事实出处：§9.1（漂流中可见范围与状态）、§11.1（漂流日志仅本人）、§9.2（入海解锁）、
§4.3/§11.2（完成通知文案）。

## 8. 屏 06 · 漂流的规矩（六卡 md:grid-cols-2）

- **瓶与瓶是断的** — 每个瓶子单发一个代号；一个代号，跨不出这只瓶。
- **想说"不好"，先听完 80%** — 同一段一人一票，作者不能踩自己。
- **赞只显示热度，不救生** — 斩浪只用来防捣乱，不针对人。
- **有人管** — 瓶子、段落、留言都能举报，人工审核拥有最终决定权。
- **失控有时限** — 72 小时没人接，自动退回或入海；回传决策限时 48 小时。
- **你看到的就是做出来的** — 本页介绍的每条规则都已在 Demo 里实现，顺着入口就能走到。

## 9. 屏 07 · 投出你的第一瓶（`<ol>` 三步）

1. **第一步 · 当场听一支成品** — 回到第一屏的播放器，不用注册，点开就播。
2. **第二步 · 去河道捞一个** — 随机打捞，听到别人的半句，再决定接不接。
3. **第三步 · 唱一段投进去** — 登录只在这一步之后出现；录一段，投进河里。

- 链尾 CTA（保留用户指定动作词）：去开始体验 → `/login?next=%2Friver`
- 风险消除句（保留原句）：不露脸，不记名，唱完一段就可以走。
