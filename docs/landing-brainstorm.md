# Landing v2 内容头脑风暴（t12）

> 任务：t12 ① 内容团队头脑风暴。约束：三问（这是什么 / 解决谁的问题 / 现在能否体验）+
> 评委追问六段逻辑必须成立；整页翻页式呈现（每屏一段）；视觉语言只能用 DESIGN.md record-v1
> （唱片落水 · 河道 · 漂流瓶）；**最终文案不逐字照搬用户示例**（用户示例指
> "想唱但怕被评价的人，不用露脸、不用唱完、不用等点赞" 一句，及其同构排比复述）。
> 本文记录 3 个概念方向、取舍理由与最终选定方向的文案落点。

---

## 0. 判准（先立标准再开脑）

1. **钩子可画面化**：第一屏第一行必须是一个能拍出来的动作或画面，不写抽象概念；
2. **方向感 = 翻页感**：整页翻页有明确的推进方向（页码 01→07 需要一个"往哪走"的叙事）；
3. **六段可落屏**：评委追问链（是什么→怎么做→为何更好→最强场景→靠谱吗→马上试）
   能在该方向下各占一屏而不别扭；
4. **不与装置抢戏**：record-v1 的盘面/沟槽/水线已经承担信息，概念方向不能再发明一套
   与之冲突的视觉母题；
5. **CTA 有终点感**：链尾「去开始体验」要像旅程的出口，不像突然贴上去的按钮。

---

## 1. 方向 A ·「顺流」——六屏就是一段从上游到入海的航程（选定）

**概念**：把翻页的"下一页"翻译成"往下游走一屏"。页码即航程：01 出发的岸（你开口）
→ 02 河是什么 → 03 怎么把瓶子放出去 → 04 与旧河道的分岔 → 05 沿途的三种天气（场景）
→ 06 河规（信任）→ 07 入海口（去开始体验）。最后一屏的 CTA 就是"下水"的入口。

- **钩子候选**（≤16 字，画面化）：
  - 你唱上半句，河替你找下半句。（选定）
  - 唱一句就走，剩下的交给河。
  - 一支瓶子的终点，是四个陌生人的嗓音。
- **三问落位**：是什么 = 钩子下的 25 字定义；解决谁 = "给录音键前犹豫的人"价值句；
  能否体验 = 第一屏右侧免注册播放卡（当场播公海成品）。
- **翻页契合**：方向键向下 = 顺流，圆点 = 浮标，页码 = 航程刻度；reduced-motion 下
  位移消失但页码照跳，叙事不依赖动画成立。
- **风险**：河的意象在站内已被河道页大量使用（水线/剖面），landing 必须**只借方向不借构图**
  ——处理：landing 不复用河道剖面构图，只用序号、页码、"顺流/入海"的词。

**取舍结论**：✅ 选定。方向感、六段映射、CTA 终点感三项全得分；与装置的冲突用"只借方向"规避。

---

## 2. 方向 B ·「A 面 / B 面」——把六段当作一张唱片的两面曲目

**概念**：landing 是一张立在水里的唱片：A 面 = 认识（是什么/怎么做/为何更好），
B 面 = 放心（场景/靠谱/马上试），翻页 = 翻面；钩子落在"你的名字不出现在封套上"。

- **钩子候选**：正面是你的声音，背面没有你的名字。
- **三问落位**：是什么 = A 面第一曲；体验 = "把唱针放下"式试听入口。
- **优点**：与 record-v1 唱片语言同源，视觉几乎零成本。
- **风险与取舍**：
  1. 站内**每一页**都已有盘面/沟槽装置，landing 再以唱片为**叙事主角**会造成母题重复
     （DESIGN.md：每页装置要承担信息，不能只是背景——第二张唱片承担什么信息说不清）；
  2. A/B 面是"分类"逻辑，评委六段是"追问"逻辑，B 面第一屏答不了"这是什么"，
     三问首屏可达会被 A/B 边界切开；
  3. "背面没有名字"把注意力引向匿名的**身份**，而产品真正的差异是**接力共创**（机制）。

**取舍结论**：❌ 弃。视觉成本最低但叙事与装置重复、三问首屏被切开、卖点落偏。

---

## 3. 方向 C ·「深夜电台」——六段是一档节目的六个环节

**概念**：把 landing 做成深夜电台节目单：开场白 → 来信机制 → 接听方式 → 往期对比 →
听众来稿 → 台规 → 拨入热线（CTA）。碎片时间场景（通勤/睡前/午休）与"深夜听电台"
天然贴合。

- **钩子候选**：下一首歌，由一个陌生人替你唱完。
- **三问落位**：是什么 = 节目介绍；体验 = 直播间（播放卡）。
- **优点**：睡前场景情绪强，"来电即 CTA"的终点感好。
- **风险与取舍**：
  1. 电台是**收听**隐喻，而产品要卖的是**开口唱**——方向反了（旧方案恰恰是"等人听"）；
  2. "节目/环节/台规"词汇与站内"河道/瓶子/公海"术语冲突，评委看完 landing 进产品会
     遇到两套语言；
  3. 六段里的对比表与信任证据放进"节目单"都要强行转译，追问链变得绕。

**取舍结论**：❌ 弃。情绪贴合但隐喻方向与产品相反、术语分裂、六段转译成本高。

## 6. 翻页交互与方向 A 的配合（内容侧约定）

- 页码 `01 / 08` = 航程刻度，屏名 = 航段（开场/漂流瓶，是什么/…/投出你的第一瓶）；
- 每屏一段，段落不跨屏；第一屏必答三问（钩子→定义→价值句→当场试听）；
- 最后一屏是入海口：CTA「去开始体验」之后不再有内容屏（翻到底即停，不循环）。

## 7. W22 视觉提升方案（2026-09-29）

### 选定概念：一条河，一只瓶，一次完整航程

保留方向 A「顺流」与八屏文案，但不再让每屏各自摆一套水面装饰。整页只画一条从左下游向右下海口的连续河道；同一支玻璃瓶常驻在翻页轨道之外，每翻一屏沿河移动一段。远处仅留三支低对比备选瓶，负责交代“这里还有别人的声音”，不与主瓶争夺注意力。末屏海口扩大，主瓶抵达公共作品集。

### 紧凑视觉系统

- 色彩：只组合项目现有 `ink / water-bed / water-body / water-surface / glass / coral / warm`；深水为底、珊瑚只标行动，暖色只落在瓶中卷纸。
- 字体：中文继续用霞鹜文楷承担叙事；Quattrocento 仅用于航程刻度与极短状态，不新增字体资源。
- 布局：桌面端内容像岸上的唱片内页，左右交替让出河面；窄屏改为上方内容、下方河道，屏内允许纵向滚动，不牺牲信息。
- 质感：河道是大尺度 S 曲线与细水纹，不使用渐变卡片墙；内容面板以深水半透明底和发丝线压住复杂背景。

```text
桌面
┌────────────────────────────────────────────┐
│ 文案 / 试听                     航程刻度   │
│        ╲~~~~~ 河流 ~~~~~╱                  │
│  远瓶       [同一主瓶]       远瓶          │
└──────────────────────────────────海口──────┘

窄屏
┌──────────────────┐
│ 标题与正文（可滚）│
│ ~~~~ 河道 ~~~~~~ │
│    [主瓶]   海口  │
│  页码 · 屏名      │
└──────────────────┘
```

### 动效职责

- continuity：翻页轨道与主瓶同步推进；主瓶节点不卸载、不逐屏重建。
- guidance：当前航段由页码、屏名、圆点和主瓶落点共同说明，动效不是唯一反馈。
- decoration：远瓶只保留低对比静态姿态；河纹不循环抢注意力。
- reduced-motion：轨道与瓶子即时抵达新位置，内容、页码、键盘和触控功能保持完整。

### 自检与取舍

初稿曾考虑每屏一张“功能卡 + 小插画”，但它会落入同构卡片模板，也无法满足“一支瓶贯穿全程”。最终把唯一强视觉收敛到连续河流；卡片只在对比表、规则和操作步骤确实需要分组时出现。页面不新增依赖、不改全局 token、不使用外部图片。
